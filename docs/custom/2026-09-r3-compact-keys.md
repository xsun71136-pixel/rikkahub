# R3：Key 界面收敛与按错误独立自定义（先设计）

基线：R2源码25c904bd、文档0c311ef，本地5d86c01。用户反馈：两个Key页面过大、杂乱，原多Key布局更好；只需要原功能适量扩展，策略自定义仍不足。本轮不改自动重试与消息保存链。

## UI收敛
- 两页均恢复内容自适应底部弹窗，上限屏幕82%、大屏宽度560dp，不强制全高。
- 多Key：标题+可用数量一行；随机/轮询；添加/导入+搜索开关+更多；紧凑两行列表（别名/掩码/状态、开关、测试、更多）。撤下常驻统计卡、筛选芯片墙、每Key大卡与多行文字操作。搜索/筛选按需展开，批量操作藏在更多，编辑删除恢复藏条目更多。保留去重提示、测试超时/成功后恢复/取消保护等后端修复。供应商配置页去掉新增大卡和重复标题。
- Key策略：总开关+3条自然语言规则；点一条只编辑该类。默认显示“无效Key → 停用24小时 / 额度不足 → 停用24小时 / 限流 → 冷却1分钟”。不展示一屏滑条。自定义规则和切换选项默认折叠，说明默认折叠。保存固定在底部，草稿与放弃确认保留。

## 实质自定义
1. 三类分别设动作、冷却初始/上限/倍率、停用分钟数/永久（不再共用一组恢复时长）。字段精确输入并校验，先给常用时间选项，高级冷却参数按需显示。
2. 可新增自定义规则：名称、启用、HTTP 400~499状态码、错误包含词（不区分大小写），命中后执行独立处置。设置两种条件时须同时满足；同类内部任一满足。按列表第一条匹配生效，可调整优先级；全空条件禁止保存，避免全匹配。
3. 默认规则不改变：普通403不处罚、5xx硬保护，取消/Key池耗尽不处罚。用户显式新增403/某错误词规则才处理对应错误。健康文件只记custom分类，不存上游内容/关键词。自定义条件仅对单次请求实际Key生效，不扫描其他Key。
4. 旧全局字段保留用于兼容，独立配置为空时从R2全局值生成，旧备份行为不变；旧action和until记录保持，策略更改仅影响后续失败。

静态检查更新为行为检查，不为了旧字符串断言削弱新功能；新增独立时长/规则优先级/AND语义/无条件禁用/5xx及取消保护测试。云端测试与构建、下载校验后更新主MD，明确未做设备审美验收。先减少页面噪音，不再加仪表盘。
